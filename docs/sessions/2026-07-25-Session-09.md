# Project Guardian - Session 09

**Date:** 2026-07-25

## Objective

Implement and test the reusable logging module.

## Progress

- Implemented parameter handling with local variables.
- Validated argument count and empty values.
- Restricted log levels to INFO, WARNING and ERROR.
- Added explicit errors through STDERR and non-zero return codes.
- Generated timestamps and formatted consistent log entries.
- Tested valid and invalid execution paths.
- Used `bash -n` and numbered source output to troubleshoot syntax errors.

## Engineering lessons

Bash spaces can be syntactic rather than cosmetic. Functions should fail fast when their contract is violated and should return control to their caller instead of terminating the entire program.

The most important result was not only a working logger, but learning to move from problem definition to responsibility, inputs, outputs, failures, pseudocode and finally implementation.

## Next session

Move the logger to `lib/`, integrate it into the backup script and create automated tests.
